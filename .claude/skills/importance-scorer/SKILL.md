# importance-scorer

## 역할
수집된 각 항목에 중요도 등급(상/중/하)을 부여한다.

## 판단 기준 (우선순위 순)
| 등급 | 기준 |
|------|------|
| 상 | 소관 상임위 심사·의결 임박 법안·예산안, 예산·재정 규모(억원/조원) 명시 |
| 중 | 시행령·고시·정책 변경, 신규 계획 발표, 연구기관 주요 보고서 |
| 하 | 단순 동정·행사성 보도자료, 인사·위촉, 간담회 |

## 사용자 조정
`feedback/feedback.md`에 아래 형식으로 기록하면 자동 반영:
```
BOOST: 반도체, AI, 예산심의
PENALTY: 간담회, 행사, 협약
```
