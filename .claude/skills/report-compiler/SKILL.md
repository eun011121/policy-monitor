# report-compiler

## 역할
스코어링된 항목을 `archive/날짜/report.md`로 정리한다.

## 출력 구조
1. 헤더 (날짜, 수집 건수)
2. ⚠️ 수집 실패 소스 (있는 경우)
3. 🔥 오늘의 헤드라인 Top 5 (importance=상 기준)
4. 위원회별 섹션 (산자중기위 / 과방위 / 농해수위 / 정무위)
   - 부처별 하위 그룹
   - 항목: [중요도] 제목(링크) | 출처 | 날짜 | 요약
5. 📚 연구기관 발간물 섹션
6. 🌐 공통 이슈 섹션
7. 📋 입법 현황 섹션
8. 피드백 안내

## 구현 위치
`src/generators/report_compiler.py`
