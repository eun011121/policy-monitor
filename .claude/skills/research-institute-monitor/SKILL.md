# research-institute-monitor

## 역할
`sources/research-institutes.yaml`에 등록된 연구기관의 신규 발간물(보고서 제목 + 링크)을 수집한다.

## 대상 기관
### 부처 전담 (위원회별 섹션 배치)
- 산업연구원(KIET), 중소벤처기업연구원(KOSBI), 한국지식재산연구원(KIIP)
- 과학기술정책연구원(STEPI), 정보통신정책연구원(KISDI), 한국항공우주연구원(KARI)
- 한국농촌경제연구원(KREI), 한국해양수산개발원(KMI), 한국금융연구원(KIF)

### 공통 (주제에 따라 분류)
- 한국개발연구원(KDI), 한국조세재정연구원(KIPF), 한국경제연구원(KERI)

## v1 범위
- 신규 발간물 제목 + 기관명 + 링크 수준만 자동화
- PDF 본문 요약은 v2 검토

## 분류 원칙
- 공통 기관 발간물이 거시적 주제 → "공통 이슈" 섹션
- 특정 위원회 소관 명확 → 해당 위원회 섹션
- 애매한 경우 "공통 이슈" 기본 배치 후 feedback.md로 재분류 요청 가능
